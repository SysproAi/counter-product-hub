# Counter Product Hub

A searchable product hub for counter sales staff. Search by stock code, name, brand or use ("pet PIR"), open the product page, and print or download the one-page sheet.

Static site — no server or database. Runs on **GitHub Pages**.

## Structure

```
index.html               Search hub
product.html             Product page (also the print/PDF layout) — ?code=22BV601
data/products.json       THE product list — one entry per product
products/<CODE>/
   image.(svg|png|jpg)   Product picture
   coverage.png          Optional diagram (beam pattern, wiring, etc.)
   onepager.pdf          Generated by tools/build-pdfs.js
assets/                  CSS + search code
tools/build-pdfs.js      Regenerates the one-pager PDFs from product.html
```

## Put it on GitHub Pages

1. Create a new repository on GitHub (e.g. `counter-product-hub`).
2. Upload everything in this folder (drag-and-drop on the repo page works, or `git push`).
3. Repo **Settings → Pages → Build and deployment → Deploy from a branch → `main` / root → Save**.
4. After a minute the hub is live at `https://<your-org>.github.io/counter-product-hub/`.

### About logins
GitHub Pages sites are **public** on free/Team plans (anyone with the link can view). Only **GitHub Enterprise Cloud** can restrict a Pages site to signed-in organisation members ("Private" Pages visibility). Fine for a pilot using manufacturer info; for internal pricing or a real login, move to Enterprise private Pages, Cloudflare Pages + Cloudflare Access, or similar.

## Adding a product

1. Make a folder `products/<STOCKCODE>/` and add the product `image` and any diagram (e.g. `coverage.png`). Set `"image": null` if there's no photo yet — a placeholder is shown.
2. Copy an existing entry in `data/products.json` and fill it in. Only `code`, `name`, `category`, `subtitle` and `image` are required — empty sections are hidden.
   - `category` uses `Top level › Sub level` — the top level becomes a filter chip.
   - `note` shows a red warning bar (e.g. "confirm specs before quoting").
   - `keywords` are extra search words (old codes, slang, model numbers).
   - Rows in `coverage.rows` / `specs` / `models` can take a third value `true` to highlight them.
3. Regenerate PDFs (the script warns if a sheet runs past one page): `npm install && npx playwright install chromium && npm run pdfs`
4. Commit and push — the site updates automatically.

Preview locally with `npm run serve` and open http://localhost:8080.
